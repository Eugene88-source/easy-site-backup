# easy-site-backup
Простий плагін для WordPress для резервного копіювання бази даних і файлів

## Можливості
- Сторінка **Інструменти → Easy Site Backup** в адмінці.
- Три типи копій: база даних + файли, тільки база даних, тільки файли.
- Дамп бази даних (усі таблиці з префіксом WordPress) порціями, щоб не впертися в ліміт пам'яті.
- Архівування всіх файлів сайту в ZIP (тека з бекапами в архів не потрапляє).
- Список копій із завантаженням і видаленням.

## Структура архіву
- `database.sql` — дамп бази даних;
- `files/` — файли сайту відносно кореня WordPress.

## Безпека
- Усі дії доступні лише користувачам із правом `manage_options` і захищені nonce.
- Копії лежать у `wp-content/uploads/esb-backups/` з `.htaccess` та `index.php`, імена файлів містять випадковий суфікс.
- Завантаження йде через PHP, а не за прямим посиланням.
- На Nginx `.htaccess` не працює — заборону доступу до теки треба додати в конфігурацію сервера.

## Вимоги
- WordPress 5.8+, PHP 7.4+
- PHP-розширення `zip` (ZipArchive)
